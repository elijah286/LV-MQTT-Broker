MQTT Server.lvlib:Session.lvclass:Terminate Session.vi

Set the "Destroy" flag to True if the Connection Handler terminates to force the session to be destroyed for good, no matter what the CleanSession flag state is.

If the Connection Handler does not terminate and the CleanSession flag is false, then the Session's process stops but the last state of the session is maintained for a possible client reconnection.
